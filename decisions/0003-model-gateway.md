# 0003 企业模型网关

- 日期：2026-09-27
- 状态：已采纳（用户确认：插到组织结构之前；外部 agent 默认企业模式、可由管理员放开个人模式）

参考 Magpie（github.com/yetone/magpie，MIT）：本机网关同时说 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages 三种协议并互相翻译，让所有 agent 指向同一端点、不持有厂商 key。

- **采纳**：多协议入口与互转、预设厂商表、厂商模型列表、路由组、agent 只持有网关凭据。放在 orgos 服务端而不是员工本机：计量、审计、数据驻留与 key 管理都归企业。
- **不采纳**：共享订阅（把 CLI 登录态转成模型来源）——违反各家服务条款，企业产品只用 API key。也不把 Magpie 作为依赖（发布仅数日、Go 技术栈、计量需要单点在我们的网关）。
- **与 ACP 的分工**：ACP 解决怎么驱动 agent（会话、追问、权限），网关解决它用哪个模型、哪个 key、花了多少钱。
- 外部 agent 只在任务期间持有绑定该任务的短时令牌；不修改用户的全局配置文件。
